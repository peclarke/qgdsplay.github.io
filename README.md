# QGDS Update Monitor

This tool aims to have some relevant web components from the QGDS web component library being used. This is because a lot of these components don't work yet, and I want to be able to see when they do. To that end, I've configured dependabot to make PRs on this repository with updates to the QGDS library. When the PRs are merged in, the site will auto-update. Then, you'll be able to see whether or not a component works or not by navigating to its section.
